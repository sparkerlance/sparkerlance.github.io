什麼是 API？簡單來說，API 像是「語法」。不只是在前後端之間，任何套件或框架，只要要給別人使用，都一定會有 API。前端與後端溝通時，後端通常會提供一份 API 使用說明，告訴前端在什麼情況下該呼叫哪一個 API，以及會回傳哪些資料。在遊戲公司時，像是排行榜系統，前端只要呼叫對應的 API，後端就會回傳玩家的通關時間、排名、人數，或是累積遊玩時間等資料；又或者在遊戲啟動時，前端會呼叫「啟動驗證」的 API，只要驗證通過，後端就會回傳可以進入遊戲的結果。前端不需要知道後端怎麼計算排名、怎麼驗證帳號，只要依照 API 的規則呼叫，就能拿到對應的結果。同樣的概念，也會出現在使用各種套件或框架、遊戲影擎時。 舉例來說，當我在學習 ECS（Entity Component System）時，在專案裡看到了一個檔案： [API.md] 沒有使用過套件或框架的開發者會冒出一個疑問： 什麼是 API？ 一、API 的白話文解釋API =「我可以怎麼用這個東西」 API（Application Programming Interface）簡單來說就是：「這個程式／套件提供了哪些...
