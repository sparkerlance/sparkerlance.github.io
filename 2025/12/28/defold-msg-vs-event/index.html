msg vs event

發表於2025-12-28|更新於2025-12-28
|瀏覽量:

為什麼 Defold 已經有了內建的消息系統 msg.post，實務中還使用了額外的 Event 系統？

本文所指 “額外的 Event 系統”，是由 Insality 編寫的
defold-event
https://github.com/Insality/defold-event

以下討論皆基於此類「架構層事件系統」的設計思路，而非 Defold 引擎內建的 msg 機制。

一句話結論

msg 是 Defold 的「引擎級訊息系統」
Event（如 defold-event）是「遊戲架構層的事件系統」

兩者並不重複，而是層級與責任不同。

一、什麼是 msg？

msg 的本質

  • Defold 引擎內建
  • 用於 GO / Component / Script 之間溝通
  • 強耦合（必須知道接收者 URL）
  • 與場景（collection）生命週期綁定

msg 的設計目的

讓「引擎物件」彼此溝通
而非用來承擔遊戲整體架構的協作責任

二、msg 的先天限制

❌ 1. 必須明確指定接收者

問題：

  • UI 需要反應 → 額外發送
  • Quest 需要追蹤 → 再加一次
  • 成就系統需要監聽 → 再加一次

結果是：
👉 發送端逐漸知道過多系統細節，耦合快速膨脹

❌ 2. 無法進行真正的廣播

msg 並不支援語意上的「事件廣播」，也就是：

「任何系統只要關心 PLAYER_DAMAGED，就可以自行處理」

msg 只能：

  • 指定單一 URL
  • 或有限 proxy 範圍

❌ 3. 無法脫離世界（World）存在

  • msg 只能存在於 active collection
  • 無法作為純邏輯層的溝通工具

在以下場景會特別明顯：

  • ECS（Decore）
  • Save / Load
  • UI 狀態管理
  • Backend / Analytics

三、Event 系統（以 defold-event 為例）在解決什麼？

這裡的 event，指的是
Insality / defold-event 所提供的全域事件機制。

Event 的核心特性

  • 發送端不需要知道接收者
  • 可同時有 0～N 個 listener
  • 可跨 Context（ECS / UI / Animation / Logic）
  • 純 Lua，不依賴 GO 或 collection

👉 這是一種架構層的解耦工具，
與 Defold 內建的 msg 負責的層級不同。

四、真實遊戲情境對比

情境：Player 受傷

❌ 僅使用 msg 的結果

這種模式的特徵是：

  • Player 與所有系統產生直接依賴
  • 系統一旦調整，核心邏輯必須跟著修改
  • 幾乎無法進行單元測試或重構

✅ 使用 Event 的做法

結果是：

  • Player 完全不關心「誰會使用這個事件」
  • 各系統可以自由加入或移除
  • 架構可長期演進而不崩壞

五、為什麼 Defold 不直接內建 Event？

原因在於引擎層與架構層的分工不同。

引擎層 vs 架構層

層級 責任
Defold Engine GO / Scene / Rendering / Physics
Event System Gameplay / 狀態變化 / 系統協作

類似情況也存在於 Unity / Unreal：

  • 引擎提供 message / callback
  • 實務上仍會自行建立 Event / Signal / Delegate 系統

六、msg 與 Event 的使用分工

適合使用 msg 的情境

  • GO ↔ GO
  • Component ↔ Script
  • Engine callback
  • 明確、具體的對象溝通

📌 例子：

  • 碰撞回調
  • Factory spawn 完成通知
  • Camera follow 行為

適合使用 Event 的情境

  • Gameplay 狀態改變
  • UI / Quest / Achievement
  • ECS System 之間協作
  • Save / Analytics / Telemetry

📌 例子：

  • PLAYER_DIED
  • ITEM_PICKED
  • QUEST_COMPLETED

七、一個實用的判斷原則

在選擇 msg 或 Event 前，可以先問一個問題：

這次溝通是否只針對「一個明確對象」？

  • 是 → msg
  • 否 / 尚不確定 → Event

八、總結

msg 比較像是肌肉訊號
Event 更接近遊戲的神經系統
