修復 Hexo Butterfly 主題的 Busuanzi 訪客計數問題

Created2025-11-11|Updated2025-11-11|網站
|Post Views:

在使用 Hexo 的 Butterfly 主題時，我遇到了 Busuanzi 訪客計數無法正常顯示 的問題。經過檢查發現，Butterfly 當前支線的 Busuanzi URL 錯誤，因此需要手動注入腳本來解決。

問題現象

  • 網頁上的訪客數、頁面瀏覽數無法顯示。
  • F12 開發者工具看到錯誤：Uncaught SyntaxError: Unexpected token '<'。
  • 原因是主題預設的 Busuanzi CDN URL 錯誤或不可用。

解決方法

  1. 在 Butterfly 配置中啟用 Busuanzi 訪客計數：
  1. 手動 inject 正確的 Busuanzi 腳本到頁面底部：

這裡手動 inject 是因為 clone 當前 Butterfly 支線的 Busuanzi CDN URL 錯誤，需要改成使用這個可用的 URL。

  1. 結果：
  • 網站的訪客數 (UV)、站點總瀏覽數 (PV)、單頁瀏覽數 (page PV) 都能正常顯示。
  • 不再出現 <script> 相關的錯誤。(因為Busuanzi網址錯誤導致請求回復404的html，理論上成功時是回復js)

小結

當遇到 Hexo Butterfly 主題某些功能無法使用時，可以透過手動注入腳本的方法解決，尤其是第三方統計工具的 CDN URL 錯誤或過期的情況。
